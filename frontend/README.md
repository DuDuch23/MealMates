# MealMates — Frontend

Application React 18 + Vite + Tailwind CSS v4.

```bash
cp .env.example .env   # renseigner les variables VITE_*
npm install
npm run dev            # http://localhost:5173
```

Scripts : `dev`, `build`, `lint`, `preview`.

Documentation complète du projet (architecture, variables d'environnement, conventions) : [CLAUDE.md](../CLAUDE.MD) à la racine du repo.
